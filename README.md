#  Global Space Mission Analysis (1957 - 2020)

###  Project Overview
This project provides an end-to-end Exploratory Data Analysis (EDA) of every space mission since the launch of Sputnik. 

###  Technical Implementation
- **Data Wrangling:** Handled complex string parsing and ISO-3166 country standardization.
- **Visualizations:** Created interactive Choropleth maps, Sunburst charts, and Time-Series analysis using Plotly.
- **Key Analysis:** Tracked the shift from Cold War geopolitics to the modern commercial space era.

###  Key Findings
- **The SpaceX Effect:** Average launch prices have plummeted by nearly 8x since 2010.
- **Risk Evolution:** Global failure rates dropped from ~40% in the 1960s to a stable ~5% baseline today.
